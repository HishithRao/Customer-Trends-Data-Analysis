# 🛍️ Customer Shopping Behavior — Data Analyst Portfolio Project

An end-to-end data analytics project analyzing customer shopping trends and behavior, covering the full workflow from raw data to business-ready dashboard: **Python (cleaning & EDA) → SQL (business analysis) → Power BI (visualization) → Insights report.**

This project was built to demonstrate the core skill set expected of a Data Analyst: data preparation, relational data modeling, SQL analysis, dashboard design, and clear business communication.
